# Kumo Sprint Wheel

Spin to pick this week’s Kumo sprint moderator and backup.

**Share this with colleagues:** https://alexnicohey.github.io/KumoWheel/

## Start

Needs [Node.js](https://nodejs.org/) 20 or newer.

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.
